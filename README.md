# Portfolio Analysis and Optimization

This repository contains projects in quantitative finance, focusing on portfolio construction, risk measurement, and performance analysis using Python.

## Projects

### 1. Mean-Variance Portfolio Optimization
- Implementation of the Markowitz model
- Construction of the efficient frontier
- Analysis of the risk-return trade-off

### 2. Portfolio Risk Analysis (VaR & Expected Shortfall)
- Historical Value-at-Risk (VaR)
- Parametric VaR (variance-covariance method)
- Monte Carlo simulation
- Expected Shortfall (CVaR)
- Risk estimation at 95% and 99% confidence levels

### 3. Portfolio Risk-Return Analysis
- Analysis of portfolio performance
- Study of returns, volatility, and drawdowns
- Visualization of risk-return profiles

### Tools and Technologies: Python, NumPy, Pandas, Matplotlib, SciPy, yfinance

## Key Concepts
- Portfolio diversification
- Risk-return trade-off
- Volatility and correlation
- Tail risk and extreme losses

## Objective
The goal of this repository is to demonstrate how quantitative methods and Python can be used to:
- Model portfolio performance
- Measure financial risk
- Support data-driven investment decisions
